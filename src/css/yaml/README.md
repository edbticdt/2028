# YAML framework stylesheets

These come from "Yet Another Multicolumn Layout" 3.3 by Dirk Jesse, as used
by the 2026 and 2027 editions, and are kept **unchanged**: they are licensed
CC-BY 2.0, and their headers must stay. Override them from `../site/`
instead of editing them.

`layout.css` imports the others; the page links only `layout.css`.

This file is not published: Eleventy copies only the stylesheets.
